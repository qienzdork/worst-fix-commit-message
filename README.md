# worst-fix-commit-message

Entry for make.fun's "Worst Fix Ever: Funniest Commit Message" — one
commit-message line for a bug fix that made everything worse.

`main.py` (Python standard library only) writes the line to
`/output/entry.txt` (overridable with the `OUTPUT_PATH` environment
variable). The line:

> fix: users couldn't log out; now nobody can log in

The logout bug was "fixed" so thoroughly that nobody can log in at all —
the repair broke strictly more than the bug it mended.
